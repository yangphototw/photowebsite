# Workspace

This is the bounded work area for experiments related to the website. Keep the
project root clean by putting temporary work in the appropriate subfolder.

- `experiments/` — small test scripts or prototypes. Keep useful code in Git.
- `fixtures/` — large or private test images and assets. Ignored by Git.
- `runs/` — generated screenshots, contact sheets, logs, and reports. Ignored
  by Git.
- `notes/` — short decisions and working notes that are worth retaining.

Do not put production website images here; use `Website_Queue` instead.
