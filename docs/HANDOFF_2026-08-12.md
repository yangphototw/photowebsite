| Variable | Scope | Purpose |
| --- | --- | --- |
| `PUBLIC_TURNSTILE_SITE_KEY` | client build setting | Renders Cloudflare Turnstile on the booking page. |

requests are written to the existing Google Sheet workflow; the active code no
longer sends mail through Resend.
